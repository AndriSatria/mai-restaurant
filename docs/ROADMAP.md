# Roadmap

- [x] 1. Kitchen trips: tool use sends cooks to the pantry, stove and bell
- [x] 2. Order tickets on the pass rail
- [x] 3. Subagents work as kitchen hands
- [x] 4. Approvals at the pass
- [x] 5. Resting and out-of-limit states
- [x] 6. Small reactions
- [x] 7. Dining room view
- [x] 8. Dining room everywhere
  Add the dining room to the flat view too. When there are more than 6 projects, wrap the extra tables into more rows, and serve kitchen-hand subtasks to their lead's table.
- [x] 9. The bill
  Each finished run leaves a small receipt at its project's table showing how long it took, a count of tools by kind (pantry trips, edits, commands), and tokens or cost when the CLI reports them. Hovering or clicking the receipt shows the details.
- [x] 10. Day and night service
  The kitchen lighting follows the user's local clock: morning, lunch rush, evening, and a dim after-hours look. Tickets steam more as the queue gets busier.
- [ ] 11. Staff board
  A chalkboard on the wall lists each cook's name, whether it runs Claude Code or Cursor, and what it's doing now. Clicking a name opens that cook's chat.
